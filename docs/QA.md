# Likely Q&A

- Why not just a script? Reusable package, tested parsers (24 tests), stable CLI and Python API.
- Is live collection safe? No credentials are read or stored; the user logs in manually and confirms each list. No auto follow/unfollow.
- Is the result complete? Not guaranteed; metadata marks `completeness: unverified`.
- Why a PyPI name with a suffix? The plain name is likely taken; the import name stays `igfollowchecker`.
- What is original? Workflow integration and snapshot diffing, stated honestly.
